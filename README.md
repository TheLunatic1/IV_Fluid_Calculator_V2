# IV Fluid Calculator 💧

A clean and modern **IV Drop Rate Calculator** built for clinical use. Designed for doctors, nurses, and medical students.



## ✨ Features

- **Accurate Drop Rate Calculation** (Macro 15 & Micro 60 drop factors)
- **Real-time Drop Animation** (Visual feedback)
- **Dark & Light Theme** (with persistence)
- **Copy Result** to clipboard
- **Input Validation** with smart warnings
- **Clean & Modern UI** optimized for mobile

## 🚀 Tech Stack

- **React Native** + **TypeScript**
- **Expo** (SDK 54)
- **Expo Linear Gradient**
- **AsyncStorage** (theme persistence)
- **React Native Reanimated**

## 📱 How to Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/TheLunatic1/IV_Fluid_Calculator.git
cd IV_Fluid_Calculator

# 2. Install dependencies
npm install

# 3. Start the app
npx expo start
